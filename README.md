# Mauritius Tax Calculator 🇲🇺

A Java program that calculates income tax in Mauritius.

## What it does
- Takes your salary, bonuses, and other incomes
- Asks about your marital status and dependents (Categories A-E)
- Calculates medical reliefs and loan interest deductions
- Shows how much tax you need to pay

## How to use
1. **Compile**: `javac TaxCalculator.java`
2. **Run**: `java TaxCalculator`
3. **Follow the prompts** and enter your information

## Example
Enter Surname : Ram
Enter Other Name(s) : Kumar
Enter yearly salary : Rs 500000
... (program calculates your tax)
